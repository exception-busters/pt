# 요구사항 문서

## 소개

회원가입 화면에 닉네임 입력 필드를 추가하고, 입력된 닉네임이 Supabase의 display name으로 저장되도록 하는 기능입니다.

## 요구사항

### 요구사항 1

**사용자 스토리:** 사용자로서, 회원가입할 때 닉네임을 입력하고 싶다.

#### 수락 기준

1. 회원가입 화면에 닉네임 입력 필드가 있어야 한다
2. 닉네임 필드는 필수 입력 항목이어야 한다
3. 닉네임은 2-20자 사이여야 한다
4. 회원가입 시 닉네임이 Supabase의 display name으로 저장되어야 한다

### 요구사항 2

**사용자 스토리:** 사용자로서, 입력한 닉네임이 내 프로필에 표시되기를 원한다.

#### 수락 기준

1. 회원가입 완료 후 사용자 프로필에서 닉네임이 표시되어야 한다
2. Supabase auth의 user metadata에 display_name으로 저장되어야 한다
3. 앱 내에서 사용자 식별 시 닉네임이 사용되어야 한다
