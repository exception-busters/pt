# 실행 방법

프로젝트를 새 환경에서 실행하거나 Supabase Edge Function을 수정한 뒤 다시 배포할 때 필요한 핵심 절차를 정리했습니다.

## 1. 사전 준비
- Flutter SDK가 설치돼 있어야 합니다. (`flutter --version`으로 확인)
- Node.js/npm이 설치돼 있어야 Supabase CLI를 `npx supabase` 형태로 실행할 수 있습니다.
- Android/iOS 에뮬레이터 또는 실제 기기를 준비하세요.

## 2. Flutter 의존성 설치 및 실행
1. 프로젝트 루트에서 의존성을 설치합니다.
   ```bash
   flutter pub get
   ```
2. 필요 시 코드 생성기가 있다면 실행합니다. (현재는 필수 단계가 없습니다.)
3. 앱을 실행합니다.
   ```bash
   flutter run
   ```

## 3. Supabase Edge Function 준비

### 3-1. Supabase 프로젝트 연결 (최초 1회)
Supabase CLI가 현재 프로젝트를 올바른 원격 프로젝트에 연결해야 합니다.
```bash
npx supabase link --project-ref wkmnnzndtggrlrzjlncn
```
프로필을 묻는다면 기본값(`supabase`)을 사용하면 됩니다.

### 3-2. 함수 비밀값 설정/갱신
새 환경에서 설정하거나 키를 교체할 때 사용합니다.
```bash
npx supabase secrets set \
  OPENAI_API_KEY="새로운 OpenAI 키" \
  SUPABASE_URL="https://wkmnnzndtggrlrzjlncn.supabase.co" \
  SUPABASE_ANON_KEY="eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```
서비스 롤 키 등 추가로 필요한 값이 있다면 동일한 명령에 붙여서 설정하면 됩니다.

### 3-3. 로컬에서 함수 테스트
로컬 `.env` 값을 사용해 함수를 돌리고 싶을 때:
```bash
npx supabase functions serve diet-recommendation --env-file supabase/.env
```
에뮬레이터/디바이스에서 Edge Function을 호출하면 콘솔에서 로그를 확인할 수 있습니다.

### 3-4. 함수 배포 (코드 수정 시마다)
Edge Function 소스를 수정한 뒤에는 반드시 재배포해야 변경 사항이 적용됩니다.
```bash
npx supabase functions deploy diet-recommendation
```
배포가 끝나면 앱에서 다시 함수를 호출해 정상 동작을 확인합니다.

## 4. 문제 해결 팁
- 함수 호출이 500 에러를 반환할 경우, `npx supabase functions serve ...`로 로컬 실행 후 로그를 확인하거나, 실제 배포 환경에서는 Supabase 대시보드의 Function Logs에서 세부 오류를 확인하세요.
- OpenAI 응답이 JSON 코드 블록 형태로 오는 경우 함수가 내부적으로 코드 펜스를 제거하도록 해두었지만, 예상치 못한 형식이 나오면 로그 메시지를 참고해 프롬프트를 조정합니다.
- 새로운 비밀값을 설정했다면, 잊지 말고 바로 함수 재배포 명령을 실행하세요.
