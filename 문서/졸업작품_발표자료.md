## 핵심 기술 I: ML Kit 자세 추정

### 🤖 Google ML Kit Pose Detection

**포즈 랜드마크 33개 지점 실시간 추적**

- 어깨, 팔꿈치, 손목, 골반, 무릎, 발목 등 주요 관절
- 각 관절의 3D 좌표 (x, y, z) + 신뢰도 점수

<br/>

### ⚙️ 자세 분석 알고리즘

```dart
// 스쿼트 자세 판정 예시
double kneeAngle = calculateAngle(hip, knee, ankle);
double hipAngle = calculateAngle(shoulder, hip, knee);

if (kneeAngle < 90 && hipAngle < 100) {
  return "정확한 자세입니다!";
} else if (kneeAngle > 120) {
  return "무릎을 더 구부려주세요";
}
```

<br/>

### ✅ 기대 효과

- 부상 위험 감소 (정확한 자세 유도)
- 운동 효율 증가 (실시간 피드백)

## 핵심 기술 II: AI 맞춤 추천

### 🧠 OpenAI GPT-4 기반 추천 엔진

**운동 루틴 추천**
- 사용자 입력: 목표(다이어트/근육증가), 레벨, 운동 경험, 선호 부위
- AI 분석: 개인 특성 고려한 주 3-5회 루틴 생성
- 출력: 운동명, 세트/횟수, 휴식 시간, 예상 소요 시간

<br/>

**식단 추천**
- 사용자 입력: 목표 칼로리, 식단 유형(균형/저탄수/고단백), 제한 식품
- AI 분석: 영양소 균형 맞춤 하루 3끼 구성
- 출력: 식단 메뉴, 칼로리, 탄수화물/단백질/지방 비율

<br/>

### 🔄 학습 사이클

**사용자 피드백 → 추천 개선 → 만족도 향상**

## 기대 효과 및 활용

### 💡 기대 효과

**개인 사용자**
- 퍼스널 트레이닝 비용 절감 (월 30-50만원 → 무료)
- 시간·장소 제약 없이 운동 가능
- 부상 위험 감소 및 운동 효율 증가

<br/>

**산업적 활용**
- 헬스케어 산업: 병원·재활센터 보조 도구
- 기업 복지: 직원 건강관리 프로그램 연동
- 교육 분야: 체육 수업 자세 교정 도구

<br/>

### 📈 시장성

- **글로벌 피트니스 앱 시장**: 연평균 21.6% 성장 (2023-2030)

## 한계 및 향후 과제

### ⚠️ 현재 한계점

**① 자세 인식 제약**
- 카메라 각도에 따른 인식률 편차
- 복잡한 동작(버피, 크로스핏 등) 정확도 낮음

**② AI 추천 개인화 부족**
- 초기 추천은 일반적 템플릿 기반
- 장기 사용자 피드백 데이터 부족

**③ 오프라인 기능 제한**
- 네트워크 없이는 AI 추천 불가

<br/>

### 🚀 향후 개선 방향

- **자세 인식 고도화**: 3D depth 센서 활용, 복잡한 동작 학습
- **협업 필터링**: 비슷한 체형·목표 사용자 데이터 기반 추천
- **웨어러블 연동**: 스마트워치 심박수·칼로리 실시간 동기화
- **소셜 기능**: 친구와 운동 목표 공유 및 경쟁
